# 🎂 生日祝福小站

纯静态、零依赖的生日网站。**双击 `index.html` 即可在浏览器打开**，也可以部署到 GitHub Pages / Vercel 等任何静态托管。

## 🔐 门禁机制

全站上了锁：直接打开首页/祝福/回忆/彩蛋任一页面，若未解锁会被**自动弹回 `unlock.html`**。
必须答对三个暗号（姓名 `李梨` / 密码 `20261113` / 生日 `19`）才能解锁；解锁状态存在浏览器 `localStorage`（键 `bday-unlocked`），之后访问任意页面直接放行。

> 想重新上锁（比如换人测试）：浏览器控制台执行 `localStorage.removeItem('bday-unlocked')` 即可。
> 注意：纯前端锁只是"礼仪门"，懂开发者工具的人仍可绕过，请勿当真实隐私屏障。

## ✨ 五个页面

| 页面 | 文件 | 内容 |
|---|---|---|
| 解锁页 | `unlock.html` | 三重暗号门禁；解锁成功有发光徽章 + 流光大字横幅 + 彩带，顶部出现北京时间实时年龄计时器（精确到 0.00001 岁） |
| 首页 | `index.html` | 倒计时、正日子彩带雨、连点蛋糕 5 次有惊喜弹窗 |
| 祝福页 | `wish.html` | 点击蛋糕吹灭 5 支蜡烛许愿、祝福语自动轮播（可翻页） |
| 回忆页 | `memories.html` | 时间线（滚动浮现）+ 照片墙（点击放大灯箱） |
| 互动彩蛋页 | `play.html` | 盲盒金蛋、记忆翻牌（通关解锁终极惊喜）、角落隐藏星星彩蛋 |

全站通用：顶部导航、漂浮气球背景、右下角 🎵 Web Audio 合成的生日歌（无需音频文件，开关状态会记住）。

## 🛠️ 如何定制（只改 `config.js`）

```js
name: "李梨",                          // 改成 TA 的名字
birthday: { month: 11, day: 13 },         // 生日月/日（控制倒计时与正日子判定）
birthYear: 2007,                          // 出生年（计算周岁）
birthDateTime: "2007-11-13 00:00:00",     // 出生时刻（解锁页年龄计时器起点，北京时间）
unlock: { name: "李梨", password: "20261113", birthday: "19" },  // 解锁页三重暗号
wishes: [ ... ],                          // 祝福语，随便增删
timeline: [ ... ],                        // 回忆时间线，日期/标题/正文随便写
photos: [ "1.jpg", "2.jpg" ],             // 照片墙
```

### 加照片

1. 把照片放进 `assets/photos/` 文件夹；
2. 在 `config.js` 的 `photos` 里登记文件名，可带注释：

```js
photos: [
  { src: "1.jpg", cap: "2023 年的海边" },
  "2.jpg",           // 不写注释也行
],
```

没放照片时照片墙会显示占位卡片，不影响浏览。
